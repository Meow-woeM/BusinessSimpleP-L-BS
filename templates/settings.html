Setup instructions & script (click to open)
  1. In Google Drive, create a new Google Sheet (e.g. “Business Ledger”).
  2. In the sheet, open Extensions → Apps Script, delete the starter code, and paste the entire script below. Click the save icon.
  3. Click Deploy → New deployment, choose type Web app, set “Execute as” to Me and “Who has access” to Anyone, then Deploy and Authorize it (Google may warn the app is unverified — click Advanced → Go to project).
  4. Copy the Web app URL into the box above and click Save, then Sync now.
