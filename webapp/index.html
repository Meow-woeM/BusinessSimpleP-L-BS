      Backup & restore

      Your books are saved automatically in this browser. Download a backup to move them to another device (or to the desktop app — the file format is identical), and restore from a backup file at any time.

      About your data

      Everything is stored locally in this browser (nothing is uploaded anywhere). That means your books are private to this device and browser profile — clearing the browser's site data would erase them, so download a backup now and then. You can also install this page as an app: look for the install icon in your browser's address bar (Chrome/Edge) or use "Add to Home Screen" on a phone.
